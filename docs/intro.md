# Cloudflare API Documentation

Welcome to the Cloudflare API Interactive Reference.

This documentation provides comprehensive coverage of all Cloudflare APIs, including:

- **Workers & Pages** - Serverless platform APIs
- **DNS** - Domain name system management
- **Security** - DDoS protection, WAF, and security features
- **Performance** - CDN, caching, and optimization
- **Analytics** - Traffic and performance metrics
- **Account Management** - Billing, users, and settings

## Getting Started

All Cloudflare API requests:
- Use HTTPS and are served from `https://api.cloudflare.com/client/v4`
- Require authentication via API tokens, keys, or email
- Return JSON responses
- Follow RESTful principles

## Authentication

You can authenticate API requests using:
1. **API Tokens** (recommended) - Scoped tokens with specific permissions
2. **API Keys** - Global keys with account-wide access
3. **Email + Global API Key** - Legacy authentication method
